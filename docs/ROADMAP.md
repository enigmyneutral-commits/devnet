# DEEVO DEVNET — Roadmap do MVP

## Marco 0 — Especificação
- [ ] Definir objetivos, personas e casos de uso.
- [ ] Criar modelo de ameaças e limites de confiança.
- [ ] Definir formato de endereço e identidade.
- [ ] Definir licença, governança e política de contribuição.

## Marco 1 — Dois nós
- [ ] Inicializar projeto do núcleo.
- [ ] Criar identidade criptográfica por nó.
- [ ] Estabelecer conexão autenticada entre dois nós.
- [ ] Trocar mensagens com esquema versionado.
- [ ] Cobrir o protocolo com testes automatizados.

## Marco 2 — Descoberta de serviços
- [ ] Definir registro assinado de serviço.
- [ ] Implementar resolução de identificadores.
- [ ] Testar nós indisponíveis e registros inválidos.
- [ ] Documentar estratégia de bootstrap.

## Marco 3 — Primeiro serviço
- [ ] Publicar um serviço de documentação de demonstração.
- [ ] Aplicar autenticação e autorização.
- [ ] Implementar limites de recursos e timeouts.

## Marco 4 — Cliente de navegação
- [ ] Criar interface do DEEVO Browser.
- [ ] Integrar resolução de endereços DEVNET.
- [ ] Manter a web convencional isolada do contexto DEVNET.
- [ ] Não executar conteúdo remoto sem consentimento explícito.

## Marco 5 — Validação
- [ ] Testes de segurança e dependências.
- [ ] Testes de resiliência e desconexão.
- [ ] Testes de desempenho com vários nós.
- [ ] Documentar limitações conhecidas antes de qualquer beta público.
